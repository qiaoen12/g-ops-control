# Fictional example site

This is a deliberately minimal, sanitized example for an unrelated operator. It describes a fictional service shape only; it contains no hostnames, IP addresses, domains, usernames, ports, inventory, credentials, or runtime state.

An example site may link a generic Service Card and Runbook and show how a target is named abstractly. It must keep target facts and secrets in the operator’s private runtime store. Nothing here is a production deployment or a claim that a service exists.
